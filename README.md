# 던전 어드벤처 (Dungeon Game)

브라우저에서 바로 하는 흑백 먹선 + 핫핑크 스타일 횡스크롤 던전 액션 게임. 설치 없이 `index.html`만 열면 됩니다.

- 4직업(전사·마법사·궁수·도적), 직업별 스킬 20종, 장비·강화·상점
- 던전 10개, 보스 10체, 도감·업적, 상자/매복/제단 이벤트
- 난이도 4단계 + 플레이어 강해질수록 적도 강해지는 적응형 난이도

## 조작
방향키 이동 · Shift 달리기 · A 기본공격 · Q W E R F 스킬 · Tab 메뉴 · Enter 상호작용 · P 일시정지 · M 음소거
